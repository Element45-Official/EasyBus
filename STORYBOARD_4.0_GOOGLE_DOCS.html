4. Flow of Application — EasyBus Online Bus Reservation System

Project Name: EasyBus Online Bus Reservation System
Document Section: 4.0 Flow of Application (Storyboard & CRUD Operations)

4.0 Overview of Application Flow & CRUD Plan

The EasyBus system manages intercity bus ticketing and operational logistics across Malaysia. The system accommodates two main user groups:

  • Passengers (Public Users): Search available trips, view seat availability via an interactive cabin map, book seats, and track live bus status via GPS.
  • Administrators & Bus Operators: Manage trip schedules, ticket prices, driver assignments, and monitor fleet statistics through analytical dashboards.

The application flow is organized into five structured sections: Create, Read, Update, Delete, and Dashboard.

4.1 CREATE Operations

Create operations allow operators to register new bus schedules and passengers to book tickets and create accounts.

Function 1: Register New Bus Schedule

  • Description: Enables administrators to register a new bus trip between two terminals with assigned departure times, ticket fares, and bus drivers.
  • User Interface: Add Schedule Form Page (add-schedule.html) and Quick-Add Modal (schedule-list.html).
  • Form Fields & Input Controls:
    • Bus Number: Text input (e.g., ABC1234 / VJE 9021)
    • Route Assignment: Text input (e.g., Kuala Lumpur to Penang)
    • Driver Name: Text input (e.g., Ahmad Albab)
    • Available Seats: Number input (e.g., 40)
    • Departure Location: Text input (e.g., Terminal Bersepadu Selatan - TBS)
    • Arrival Location: Text input (e.g., Penang Sentral)
    • Departure Date: HTML Date Picker (e.g., 2026-06-01)
    • Departure Time: HTML Time Picker (e.g., 08:00 AM)
    • Ticket Price: Currency input (e.g., RM 35.00)
    • Trip Status: Dropdown selection (Available / Full / Cancelled)

4.2 READ (Retrieve) Operations

Read operations display records in structured data tables, interactive seat maps, and live GPS tracking dashboards.

Function 1: Display Master Bus Schedule Table with Live Search Filter

  • Description: Displays all active bus departures in a searchable administrative table with real-time text filtering.
  • User Interface: Schedule Management Table Page (schedule-list.html).
  • Table Columns & Display Elements:
    • Search Bar: Instant text search filter by bus number or destination route
    • Bus Number: Shows vehicle registration plate (ABC1234, XYZ5678, DEF9012)
    • Route: Shows departure and arrival terminals (Kuala Lumpur → Johor Bahru)
    • Date & Time: Departure timestamps (2026-06-01, 08:00 AM)
    • Price: Formatted ticket price tag (RM35.00, RM18.00, RM45.00)
    • Status Badges: Color-coded badges (Available [Green], Full [Amber], Cancelled [Gray])
    • Action Column: Quick "Edit" and "Delete" buttons for each record

4.4 DELETE Operations

Delete operations remove obsolete schedules, cancelled reservations, and decommissioned assets with user confirmation guards.

Function 1: Delete Bus Schedule Record with Confirmation Dialog

  • Description: Allows operations staff to permanently delete a cancelled or obsolete bus trip from the schedule table.
  • User Interface: Red "Delete" action button in schedule-list.html.
  • Confirmation Guard & Flow:
    1. Operator clicks the red trash can "Delete" button next to a schedule row.
    2. Browser displays a JavaScript confirmation dialog: "Are you sure you want to delete this bus schedule?"
    3. Upon clicking OK, an alert confirms deletion: "Bus schedule has been deleted successfully."
    4. The row smoothly slides out, is removed from the table, and the schedule counter updates automatically.
